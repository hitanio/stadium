# ワールドカップ学習スタジアム（ホーム画面アプリ版）

## 中身
- `index.html` … 入口（総合ランキング・宿題チェック・おうちの人メニュー）
- `sansu/` `kokugo/` `eigo/` … 各教科
- `manifest.webmanifest` `sw.js` `icons/` … ホーム画面アプリ化とオフライン用

## 公開のしかた（GitHub Pages・無料）
1. GitHub にログインし、右上の「＋」→「New repository」。名前は例えば `stadium`（Public）。
2. 作ったリポジトリで「uploading an existing file」を押し、この ZIP を展開した**中身ぜんぶ**（フォルダごと）をドラッグして「Commit changes」。
3. 「Settings」→ 左の「Pages」→ Branch を `main` / `(root)` にして「Save」。
4. 1〜2分待つと `https://<ユーザー名>.github.io/stadium/` で開けます。

## スマホのホーム画面に入れる
- iPhone：Safari で上のURLを開く →「共有」→「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「アプリをインストール」（または「ホーム画面に追加」）

ホーム画面のアイコンから開くと、全画面のアプリとして動き、電波がなくても遊べます。

## これまでの記録を引き継ぐ
1. 今までの claude.ai のスタジアムで「おうちの人」→「🔁 データ引き継ぎ」→「① 引き継ぎコードをコピー」
2. **ホーム画面のアプリ**を開き、同じ画面でコードを貼り付けて「② 読み込む」
   （iPhone はSafariとホーム画面アプリで記録が別々なので、必ずアプリ側で読み込む）

## 注意
- 記録はそのスマホの中にだけ保存されます（claude.ai 版のようなアカウント保存・Claudeへの自動ログ送信はありません）。
  ログを見て調整してほしいときは「おうちの人」→「📊 プレー記録を見る」→「記録をコピー」で Claude に貼り付けてください。
- 機種変更のときは「データ引き継ぎ」で移せます。
- 無料の GitHub Pages は公開リポジトリなので、URLを知っている人は開けます（子どもの記録はスマホ内だけで、外には出ません）。

## 更新するとき
新しいファイルを同じ場所に上書きアップロードし、`sw.js` の `VERSION`（例 `wcs-v1` → `wcs-v2`）を1つ上げます。
アプリを1〜2回開き直すと新しい版になります。
